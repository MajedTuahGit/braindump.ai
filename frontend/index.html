⊕ Local Model Training School

Learn how to compile, train, and compress the local machine learning models that power BrainDump.AI.
1. TIER 1: SVM PIPELINE TRAINING Phase 5
On initial startup, Tier 1 runs on raw keyword overlapping regex rules. Once you have accumulated enough data, you can train a lightweight machine learning classifier (TF-IDF vectorizer + Support Vector Machine) which learns actual word weights:
python training/train_tier1.py
This builds a scikit-learn pipeline, exports it to models/tier1_svm.pkl, and shifts prediction from basic keywords to probability distributions.
2. TIER 3: BERT TEACHER MODEL FINE-TUNING Phase 6
To handle complex language structures and establish a highly accurate oracle/teacher, we fine-tune a heavy transformer model (bert-base-uncased) on our classified database:
python -m ml.slm.01_teacher.train_teacher
This saves a full-precision PyTorch sequence classifier in models/teacher_bert/.
3. TIER 2: DISTILL, PRUNE, & QUANTIZE SLM Phases 7 - 9
Since running a full BERT model locally takes ~280ms on CPU, we use the teacher to distill a fast Student model (MiniTransformer) and compress it via Weight Pruning and Dynamic Quantization (FP32 → INT8):
python -m ml.slm.02_distillation.distill_train
python -m ml.slm.03_pruning.run_pruning
python -m ml.slm.04_quantization.quantize_dynamic
This produces models/student_quantized.pt which runs in ~8ms while preserving 95%+ of the BERT teacher's classification quality.
